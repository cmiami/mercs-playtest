# Mercs: playtest builds

Early playtest of a 2D side-view shooter. Download the latest build from **[Releases](../../releases/latest)**.

## ▶ Play in browser
**[Play in browser](https://cmiami.github.io/mercs-playtest/play/)**: no install. A desktop browser with WebGL 2 (Chrome, Edge, Firefox or Safari), a keyboard and a mouse. The first load downloads about 105 MB. Click the game to give it focus; the character pick starts the sound. The Fullscreen button is under the game.

## Windows
1. Download `Mercs-Windows.zip` and unzip it.
2. Run `Mercs/Mercs.exe`.
3. If Windows says "Windows protected your PC", click **More info → Run anyway**. The build isn't code-signed.

## Controls
| Key | Action |
|---|---|
| A / D | Move |
| W / ↑ | Up stairs, enter doors, hide |
| S / ↓ | Down stairs |
| Shift | Sprint |
| C | Crouch |
| Mouse | Aim, left click fires |
| Right mouse (hold) | Aim down sights: tighter spread, crosshair |
| E | Interact / loot |
| T | Taunt (draws enemies) |
| R | Restart after death |

Mature content: strong language and satire.

Feedback welcome: what felt good, what felt bad, and where you got stuck.
